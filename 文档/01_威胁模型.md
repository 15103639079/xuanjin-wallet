# 威胁模型

默认桌面应用以只读方式查询 BTC 和 ETH 公开地址。开发者可显式开启离线实验室，使用测试助记词验证地址派生。真实资产的密钥管理应交给独立签名设备。

- **静默盗转。** 只读客户端持有公开地址，无法独立授权支出。测试链的协调钱包仅持有公开描述符。签名节点验证收款地址、金额、找零和手续费。当前签名节点是软件模拟，硬件设备集成尚未验证。
- **界面和剪贴板被篡改。** 受控制的 Mac 可以展示虚假地址或篡改待签名交易。使用独立设备的屏幕核对收款地址和交易明细，才能把确认步骤放到电脑之外。
- **助记词被读取。** 库中的 Apple 安全隔区（Secure Enclave）可用 P-256 密钥包裹助记词。比特币和以太坊的 secp256k1 签名无法直接用该密钥执行。应用内解包时，明文会进入进程内存。系统级入侵者可能读取该内存。 [Apple 安全隔区说明](https://developer.apple.com/documentation/Security/protecting-keys-with-the-secure-enclave)
- **查询结果被篡改或过期。** 应用使用固定 HTTPS 服务，拒绝 HTTP 重定向。服务仍能返回过期或错误数据，查询目前也会把公开地址及请求元数据暴露给服务。查询时间只表示客户端获取结果的时刻。
- **签名设备丢失。** 本地测试覆盖了从 Bitcoin Core 软件钱包备份恢复、核对原地址和重新签名。实体设备恢复需要在对应设备上单独演练。

环境检测和测试向量可提供部分信号。发布版本尚未做独立安全审计，也没有验证对已被控制的操作系统能检测到哪些攻击。
