# 开发路线

## 比特币签名与恢复验证

安装 Bitcoin Core 命令行工具和 Python 3 后，从项目根目录运行：

```bash
python3 Scripts/bitcoin-regtest.py
```

如果工具未加入终端搜索路径，可附加 `--bin-dir /路径/bitcoin/bin`。脚本使用临时目录启动两个关闭对等网络的 Bitcoin Core 本地测试节点。协调钱包只导入公开描述符。签名节点核对交易后，卸载原钱包并从测试备份恢复，再用恢复的钱包签名。协调节点验证交易、广播并挖出一个区块。退出时清理临时钱包和节点。测试币只在这次本地链运行中有效。

脚本使用 Bitcoin Core 软件签名模拟独立设备的角色。硬件设备屏幕确认、真实硬件恢复和桌面应用集成仍待验证。

参考 [Bitcoin Core 的 PSBT 流程](https://github.com/bitcoin/bitcoin/blob/master/doc/psbt.md) 和 [钱包恢复接口](https://bitcoincore.org/en/doc/25.0.0/rpc/wallet/restorewallet/)。

## 下一阶段

- 接入硬件设备，在测试环境核对收款地址、签名并验证备份恢复。
- 将经过验证的部分签名交易流程接入桌面应用，明确区分测试网与主网。
- 完成独立安全审计、依赖审查、签名发布和跨版本验证。
